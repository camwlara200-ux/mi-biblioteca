# Mi Biblioteca

Aplicación web para administrar una biblioteca personal de libros (alta, listado, edición, eliminación, búsqueda y filtros).

## Tecnologías
- HTML, CSS y JavaScript
- Supabase (base de datos PostgreSQL en la nube)
- GitHub (repositorio) y Render (publicación)

## Cómo usarlo
1. Crear la tabla ejecutando `schema.sql` en el SQL Editor de Supabase.
2. Pegar la URL y la clave publishable en `config.js`.
3. Abrir `index.html` o acceder al enlace publicado en Render.

## Seguridad
Solo se usa la clave publishable (anon) en el navegador. La tabla tiene RLS activado con políticas explícitas.
